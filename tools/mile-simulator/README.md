# マイル計算機

手持ちのポイントを JAL・ANA マイルに換算した場合の目安を比較する、単一 HTML ファイルのシミュレーターです。ブラウザで [mile.html](./mile.html) を開くと使えます。外部ライブラリやサーバー側の処理は不要です。

## 使い方

1. 各ポイントの「通常ポイント数」と、入力欄がある場合は「期間限定ポイント数」を入力します。入力のたびに結果が更新されます。
2. 「集計条件」で交換先（両方・JALのみ・ANAのみ）、優先方針、みずほANAマイレージルートの利用有無を選びます。
3. 「計算結果サマリー」で条件別の合計と JAL・ANA の内訳を確認し、「ポイント別詳細表」と「最適ルート一覧」で各ポイントの比較結果を確認します。

入力カードと集計条件は開閉できます。カードは並べ替えられ、入力があるカードだけを開く操作もできます。「リセット」はポイント入力値を 0 に戻します。

## 計算の前提

以下は**この計算機に設定した仮定のレート**です。実際の交換可否、交換単位、条件、上限、所要日数を保証するものではありません。

| ポイント | JAL通常 | JALキャンペーン | ANA通常 | ANA特殊ルート | 期間限定欄 |
| --- | ---: | ---: | ---: | ---: | --- |
| 楽天ポイント | 50% | 62.5% | 50% | なし | あり |
| dポイント | 50% | 60% | 対象外 | 対象外 | あり |
| Vポイント | 対象外 | 対象外 | 50% | 70% | あり |
| Ponta | 50% | 62.5% | 対象外 | 対象外 | あり |
| WAON POINT | 対象外 | 対象外 | 50% | 70% | 設定なし |
| PayPayポイント | 対象外 | 対象外 | 50% | 70% | あり |
| nanacoポイント | 対象外 | 対象外 | 50% | なし | あり |
| リクルートポイント | 50% | なし | 対象外 | 対象外 | あり |
| 永久不滅ポイント | 50% | 60% | 60% | 70% | 設定なし |
| エポスポイント | 50% | なし | 50% | 70% | 設定なし |
| モッピー | 50% | 80% | 50% | 70% | 設定なし |
| ハピタス | 50% | 62.5% | 50% | 70% | 設定なし |

- マイル数は、交換対象のポイント数にレートを掛け、**ポイントごと・ルートごとに小数点以下を切り捨て**ます。合計は切り捨て後のマイル数を足します。
- JALでは期間限定ポイントを換算しません。ANAでは **Vポイントの期間限定ポイントのみ**通常・特殊ルートの換算対象に含めます。その他の期間限定ポイントは対象外として表示します。
- キャンペーンや特殊ルートのレートが「なし」の場合、その比較欄には通常レートの結果を代わりに表示します。
- ANA特殊ルート 70% は「みずほANAマイレージルートを利用する」にチェックした場合のみ計算します。未チェック時は通常レートの結果を表示し、サマリーの特殊ルートを考慮したカードは表示しません。
- 交換単位・最低交換数・キャンペーン適用条件・交換上限は計算に含めていません。

## 集計条件と結果の読み方

- 「JAL・ANA両方」はポイントごとに JAL と ANA の交換先を選び、内訳も表示します。「JALのみ」「ANAのみ」は選んだ側に交換できるポイントだけを集計します。
- 「効率優先」は各ポイントでマイル数が多い側を選びます。同数なら JAL を選びます。「JAL優先」「ANA優先」はその側に交換可能ならマイル数にかかわらず選び、交換不可のときだけ反対側を選びます。優先方針は「両方」モードで適用されます。
- 「通常レート最適」は双方の通常レートを比較します。「ANA特殊ルート考慮」は ANA 側に特殊ルートを適用し、「JALキャンペーン考慮」は JAL 側にキャンペーンを適用します。両方を考慮した結果も、みずほ条件が有効な場合に表示します。
- 「最適ルート一覧」とその合計は、選択中の交換先・優先方針と、利用できるキャンペーン・特殊ルートを反映します。「最適」は上記の優先方針による判定であり、必ずしも数値上の最大値を意味しません。
- 「JAL優遇」「ANA優遇」は、利用可能なルートのマイル数に基づく画面上の分類です。公式サービスによる優遇指定ではありません。

## 保存とリセット

ポイント入力値、集計条件、カードの並びと開閉状態はブラウザの `localStorage` に保存され、再読み込み時に復元されます。保存先は計算機を配信しているページのオリジンです。入力値をサーバーへ送信する処理はありません。ブラウザの保存制限や閲覧データの削除により、復元できない場合があります。

「リセット」は**ポイント入力値の保存だけを削除**し、集計条件・並び・開閉状態は維持します。

## 設置方法

`mile.html` をそのまま Web サーバーに配置できます。WordPress 等の記事には iframe で埋め込めます。

```html
<iframe
  id="mile-simulator-frame"
  title="マイル計算機"
  src="https://example.com/tools/mile-simulator/mile.html"
  style="display:block;width:100%;height:900px;border:0"
  loading="lazy"
></iframe>
<script>
  window.addEventListener("message", function (event) {
    const frame = document.getElementById("mile-simulator-frame");
    if (!frame || event.source !== frame.contentWindow) return;
    if (event.origin !== new URL(frame.src).origin) return;
    if (event.data?.type !== "mile-simulator-height") return;
    const height = Number(event.data.height);
    if (Number.isFinite(height) && height > 0) frame.style.height = height + "px";
  });
</script>
```

`src` は実際の公開 URL に置き換えてください。計算機は内容の高さを親ページへ `postMessage` で通知します。親ページのスクリプトは送信元のウィンドウとオリジンを確認してから iframe の高さを更新します。WordPress 側で記事内のスクリプトが除去される場合は、同じ処理をテーマやサイト側の JavaScript に配置してください。

## 注意事項

このツールは交換目安を計算するためのものです。キャンペーンと特殊ルートは常設とは限りません。実際の交換前に、対象サービスと航空会社の公式サイトで最新の条件を確認してください。レートの変更時は `mile.html` 内の `pointRules` を更新します。
